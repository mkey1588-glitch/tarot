# 命式エンジンの照合について

はじめまして。こちらで組んだ命式の計算が、先生の作法と合っているかを
確認させてください。CLAUDE.md でいう「gate 1」にあたり、これが済むまで
実際のお客様には出しません。

## お願いしたいこと

先生ご自身が手で立てた命式を、`charts_template.csv` の形式でいただけますか。
20〜30 件ほどあれば十分です。多いほど確かになりますが、**23時台の出生**と
**節気の変わり目に近い出生**が数件ずつ入っていると特に助かります。そこが
流派によって割れるところだと理解しています。

わかる柱だけで構いません。空欄は照合しません。

## こちらで何をするか

デモのサイトに **「命式の照合」** のページがあります。CSV をそのまま
貼り付けていただければ、その場で結果が出ます。ターミナルは不要です。

同じことをコマンドでも実行できます。

```bash
python3 scripts/practitioner_review.py docs/practitioner/charts.csv
```

一致・不一致を出したうえで、**不一致がなぜ起きたか**を分けて表示します。

| 分類 | 意味 |
|---|---|
| 一致 | そのまま |
| **P1** | 早子時/晩子時。日柱を23時で繰り上げるか、子の刻まで持つか。既定は繰り上げですが、これは仮置きです |
| **P2** | 地方時修正。既定は「時計の時刻をそのまま」です。修正すると合う場合、どの経度なら合うかを出します |
| 精度 | 節気の境界に近く、こちらの計算誤差（±15分）の範囲。作法の違いではありません |
| **未説明** | 上記のどれでもないもの。こちらの不具合か、まだ実装していない作法です |

**不一致のほとんどは不具合ではありません。**「未説明」に残ったものだけが、
こちらで直すべきものです。P1・P2 に分類された命式は、そのまま
`docs/DECISIONS.md` の裁定の材料になります。

## 鑑定文について

同じサイトの **「プロンプトの検討」** で、実際に命式を入れたときに AI が
受け取る文面をそのまま確認できます。system プロンプトと鑑定文の
テンプレートを編集して「組み立てる」を押すと、差し込み後の全文が出ます。

現在のものはこちらで書いた仮のもので、翻訳調を避けるために先生に書き
下ろしていただきたい部分です（P5）。固まった文面をお送りいただければ
反映します。ページ上で編集した内容は保存されません。

## 未決の論点

`docs/DECISIONS.md` に P1〜P6 として挙げています。いずれも流派で割れる
ところで、こちらで決めるべきではないと考えています。現状は仮置きの既定値で
動いており、先生の裁定があれば既定を変え、その挙動を固定する試験を足します。

- **P1** 日柱は23時で変わるか、子の刻で変わるか
- **P2** 地方時修正をするか（するなら出生地をうかがう必要があります）
- **P3** 蔵干はどの説をとるか
- **P4** 節気の境界からどれだけ近ければ自動で出さず人が見るか（現状30分）
- **P5** 鑑定文の語り口 — こちらで書いた日本語は仮のもので、先生に書き
  下ろしていただくものです
- **P6** 出生時刻が不明な三柱の命式から、何がどこまで言えるか。時柱に
  由来することには触れないよう指示していますが、その線引きが正しいか

## 計算そのものについて

節気の時刻は国立天文台の公表値 312 件（1970〜2025年）と突き合わせてあり、
節入りの誤差は最大で 9.2 分、平均 4 分ほどです。干支の割り出しはまだ
外部照合ができておらず、そこが今回お願いしたい部分にあたります。
